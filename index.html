Інструкція для iPhone XS

1. Публікація на GitHub Pages

Завантажте цей файл як index.html у новий публічний репозиторій на GitHub → перейдіть у Settings → Pages, виберіть гілку main і натисніть Save.

2. Додавання на робочий стіл iPhone (Safari)

Відкрийте сайт у Safari → натисніть «Поділитися» (квадрат зі стрілкою вгору) → «На початковий екран». Додаток відкриватиметься на весь екран iPhone XS без рамок браузера.

3. Гарантований будильник через «Команди» (Shortcuts)

Відкрийте стандартний додаток «Команди» → створіть команду з назвою Timer2H та додайте одну дію: «Запустити таймер» на 2 години. Увімкніть перемикач у налаштуваннях (⚙️) сайту — тепер системний годинник iPhone спрацює, навіть якщо Safari закрито.
